# Mindustry remade in Godot

This is a recreation of the popular tower defense factory game **Mindustry** created by **Anuke** but, coded from scratch using the Godot Game Engine.

This was primarily created as a way for me to practice creating more complex game systems/mechanics and is not meant to be a direct copy of the original game.
Therefore campaign content of Mindustry will not be included.

There will be however, a playable sandbox mode with some of the combat related units and blocks available to play around with.

Please check out the original game here [https://anuke.itch.io/mindustry](url)

I did not copy any code from the original game. Only the sprites, icons, and sound effects from Mindustry were reused.
Some code was referenced in order to get stat values for various units and blocks.
